## Description

The GetNextLine project aims to create a function that reads a file or input stream one line at a time. It returns one line per function call, including the newline character when present. The function uses a buffer to read data efficiently and can handle multiple calls until the end of the file is reached.

## Instructions

Compile the project using:

```bash
cc -Wall -Wextra -Werror *.c -o program
```

Run the program using:

```bash
./program
```
